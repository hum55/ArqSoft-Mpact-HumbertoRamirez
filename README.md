# Mpact

Plataforma web tipo SaaS para la gestión de citas, clientes y servicios en pequeños negocios locales.

## Problema

Muchos negocios pequeños (barberías, consultorios, gimnasios) administran sus citas y clientes por WhatsApp, libretas o agendas físicas, lo que provoca desorganización, citas duplicadas y pérdida de información.

## Solución

Mpact centraliza toda esa información en una sola plataforma accesible desde cualquier dispositivo.

## Stack tecnológico

- **Backend:** ASP.NET Core Web API (C#)
- **Frontend:** React + Tailwind CSS
- **Base de datos:** SQL Server + Entity Framework Core
- **Autenticación:** ASP.NET Core Identity + JWT
